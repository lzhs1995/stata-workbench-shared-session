# Research handoff and archive lessons

Use the [shared-session skill](https://github.com/lzhs1995/stata-workbench-shared-session-skill)
for source/Terminal layout, serialized stages and preserved memory. The plugin
supplies runtime capability; installing a guide does not load new backend code.
Report source, installed extension and backend identities separately. This
documentation update does not change runtime or native acceptance status and
does not require restarting Stata or VS Code.

| Observation | Required distinction |
|---|---|
| File submitted and receipt returned | Executed bytes, backend PID, rc and completion markers; log echo is not execution |
| Saved-file route passed | Simultaneous source/Terminal visibility and human intervention are separate evidence |
| A stage once succeeded | A replay entry reads declared checkpoints, preserves memory and produces new outputs |
| Equal row counts across R/Stata | Full ID/group/wave/result-key membership and precision must agree |
| Archive paths resolve | Canonical-root gates and ancestor dependencies may still prevent execution |
| New source/skill installed | A loaded extension or namespace may still run its previous version |

Use compound result identities when joining outputs. Preserve full-precision
numeric sources separately from display rounding. A repaired assembler is not
model re-estimation. Resolve unknown outcomes through the original request before
resending; a callback or hash does not establish scientific validity.

Keep an existing real root when a runner needs it, or publish a new entry and
external mapping. Do not weaken historical gates. Final ZIPs need exact
prefix/member-set, CRC/size/SHA and declared source-mapping checks. The reusable
[manifest link checker](https://github.com/lzhs1995/thesis-refiner/blob/main/references/delivery-manifest.md)
generates local delivery links; integrity does not replace scientific or listening review.
